# Source dataset

`Operations_Dataset.xlsx` is the supplied synthetic operations workbook. It contains these sheets:

| Sheet | Description |
| --- | --- |
| Start Here | Workbook guidance |
| Departments | Five department records |
| Work Orders | 5,000 work orders; columns A:P |
| Calendar | Date dimension |
| Monthly Targets | Department/month targets |
| Data Dictionary | Source field definitions |

Work Orders includes ID, department ID, order type, priority, shift, created/start/due/completed dates, status, processed/defective units, rework flag, estimated/actual cost, and delay reason. The workbook's own Data Dictionary is the primary source for field descriptions.

This dataset is synthetic. Do not interpret cost, quality, or schedule figures as actual employer performance.
